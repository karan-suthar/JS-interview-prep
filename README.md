# JavaScript Interview Prep

A collection of study guides, practice pages, and planning tools for frontend engineering interviews. The materials cover JavaScript, React, browser behavior, web performance, CSS, and frontend system design.

## Getting started

Open the [frontend interview prep tracker](frontend-interview-prep-tracker.html) in a browser to browse the study plan. Select a status for each task to track your progress during the current session. The tracker does not save progress after you close or reload the page.

The guides are standalone HTML files. Open one directly in your browser; no build step or package installation is needed. The [JavaScript interview jargon and Q&A handbook](javascript_interview_jargon_qa_handbook.pdf) is a PDF reference.

## Study materials

| Area | Contents |
| --- | --- |
| [JavaScript revision](js-revision/) | Types and coercion, scope and closures, `this`, prototypes, functions, arrays, promises, async behavior, modules, and common interview puzzles. |
| [React revision](react-revision/) | Components, props and state, hooks, rendering, performance, Fiber, concurrent features, server components, data fetching, and state management. |
| [Performance and browser revision](performance-and-browser-revision/) | Browser rendering, Core Web Vitals, caching, HTTP, loading strategies, images, security, hydration, and virtualization. |
| [System design and CSS](system-design-and-css/) | Frontend architecture, feed and autocomplete design, micro-frontends, accessibility, CSS layout, cascade, theming, and component libraries. |

## Suggested workflow

1. Use the tracker to choose a topic or follow its weekly plan.
2. Read the matching revision guide and work through its examples or exercises.
3. Revisit topics that need more practice, then use the tracker to review your coverage.
